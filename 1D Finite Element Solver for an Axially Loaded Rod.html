1D Finite Element Solver for an Axially Loaded Rod

A Galerkin finite element solver, written in Fortran, that predicts how a rod deforms under distributed and end loads. Validated against closed-form solutions.

The problem

An axially loaded rod is fixed at one end and carries a distributed load p(x) plus a concentrated end load. Its displacement u(x) satisfies:

2u'' − 8u = −p(x),  x ∈ [0, π],  u'(0) = 3,  u(π) = 1

I solved two load cases: a constant load p(x) = 4 and a quadratic load p(x) = x².

Approach

  • Discretisation. The rod is split into N equal linear elements with hat-function basis, giving N+1 equations in N+1 unknowns, K·u = F.
  • Boundary conditions. The end load is added to the first load entry. The fixed displacement at x = π is enforced with a penalty term: a very large number on the last diagonal entry and the same number times the prescribed value on the right-hand side.
  • Solver. K is tridiagonal, so the system is solved with the Thomas algorithm, which needs only O(N) operations.
  • Validation. I derived both analytical solutions by hand (homogeneous plus particular solution, then boundary conditions) and compared u and u' at the nodes.

What I found

  • Both u and u' converge to the analytical solution as the mesh is refined.
  • u' converges more slowly than u. It is computed from differences between nodal values, so it is piecewise constant and only first-order accurate.
  • u' is accurate at interior nodes but least accurate at the two ends.
  • With only 25 elements the displacement error stays within about 15% of the exact answer.
  • The same code handles other load shapes by changing only the element load vector. Switching from case 1 to case 2 meant replacing two lines.

Code excerpt

! Thomas algorithm for the tridiagonal system
e(1) = A(1,1);  g(1) = B(1)/e(1)
do i = 2, N
  e(i) = A(i,i) - A(i,i-1)*A(i-1,i)/e(i-1)
  g(i) = (B(i) - A(i,i-1)*g(i-1))/e(i)
end do
Y(N) = g(N)
do i = N-1, 1, -1
  Y(i) = g(i) - A(i,i+1)*Y(i+1)/e(i)
end do
