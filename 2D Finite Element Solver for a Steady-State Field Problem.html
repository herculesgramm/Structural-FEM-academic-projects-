2D Finite Element Solver for a Steady-State Field Problem

A bilinear-element finite element solver, written in Fortran, that computes a field such as temperature across a square plate, along with its gradient. Validated against an exact Fourier series solution.

  • Fortran
  • Bilinear (Q4) elements
  • SOR iteration
  • Penalty method
  • Fourier series
  • Excel post-processing
University of Thessaly, Mechanical Engineering. Finite Element Method course, Assignment 2

The problem

Find u on the unit square that satisfies the equation below, with u = 0 on all four edges:

∇²u − u = −1,  Ω = [0,1] × [0,1]

Read as heat conduction, u is temperature at steady state. The Laplacian term is conduction, the constant is a heat source, and u = 0 on the edges holds the boundary at a fixed temperature.

Approach

  • Mesh. The square is divided into equal rectangles, hx = 1/NEx by hy = 1/NEy. Each element is mapped to a reference square with ξ, η ∈ [−1, 1].
  • Elements. Four-node bilinear Lagrange elements. Because every element has the same size, the element stiffness matrix and load vector are computed once and added into the global system at each element's node positions.
  • Boundary conditions. A penalty term is applied at every boundary node to enforce u = 0.
  • Solver. The system is solved iteratively with successive over-relaxation (SOR).
  • Gradient. ∂u/∂x and ∂u/∂y come from central differences of nodal values at interior nodes and one-sided differences on the boundary.
  • Validation. The exact solution is a double Fourier sine series over odd modes, derived by expanding in the eigenfunctions of the homogeneous problem. I compared u and both partial derivatives at every node.

Relative errors read from the report plots, so values are approximate. The relative measure is largest near the edges, where u approaches zero.

What I found

  • Gradient values at boundary nodes converge more slowly than at interior nodes, because one-sided differences are less accurate than central ones.
  • Moving outward from the centre, u falls, its relative error grows, and the gradient magnitude grows. The heat flux is largest at the boundary.
  • The four corners hold the minimum of u. Theory says the gradient is exactly zero there, which seems to conflict with the flux trend above. Mesh error at the corners is the likely reason, and worth a closer look.

Code excerpt

! SOR sweep: Gauss-Seidel update blended with the previous iterate
do while (any(abs(Ynew - Yold) > error_lim))
  Yold = Ynew
  do i = 1, N
    s = 0.
    do j = 1, i-1;   s = s + K(i,j)*Ynew(j);  end do
    do j = i+1, N;   s = s + K(i,j)*Yold(j);  end do
    Ynew(i) = (1.-w)*Yold(i) + w*(F(i) - s)/K(i,i)
  end do
end do
